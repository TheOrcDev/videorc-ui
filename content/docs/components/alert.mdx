## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";
```

```tsx
<Alert variant="warning">
  <AlertTitle>Your microphone is muted.</AlertTitle>
</Alert>
```

## Anatomy

```tsx
<Alert>
  <AlertTitle />
  <AlertDescription />
  <AlertAction />
</Alert>
```

## Examples

### Variants

The variant is the tone. `default` and `quiet` are notes (`quiet` in secondary text), `locked` says why the controls under it are off, and `success`, `warning` and `destructive` report an outcome. A title alone reads as a message in regular weight; over a description it becomes a heading in medium.

<ComponentPreview name="alert-variants" />

### Icon

Each tone brings one glyph in one weight. Pass `icon` to show the subject's own mark instead (the microphone, a platform), or `icon={null}` for none. Never put an icon in the children.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `rounded-row` | The 8 px row radius; no border and no shadow |
| `bg-foreground/4` | The tint of `default`, `quiet` and `locked` |
| `bg-success/10`, `bg-warning/10`, `bg-destructive/10` | The tone tints; the icon takes the tone colour, the text stays monochrome |
| `data-variant` | The tone, for styling a part from the alert with `group-data-[variant=…]/alert` |
| `data-slot="alert-icon"` | The leading icon |

## Accessibility

A `destructive` alert is `role="alert"` and is announced at once. Every other tone is `role="status"`, a polite live region. Pass `role` to override it, for a card that is a group or a note that should stay silent. The icon is `aria-hidden`: the title carries the meaning.
