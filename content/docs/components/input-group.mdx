## Installation

```npm
npx shadcn@latest add @videorc/input-group
```

## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
} from "@/components/ui/input-group";
```

```tsx
<InputGroup>
  <InputGroupInput
    aria-label="Search recordings"
    placeholder="Search recordings…"
  />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## Anatomy

```tsx
<InputGroup>
  <InputGroupInput /> {/* or <InputGroupTextarea /> */}
  <InputGroupAddon align="inline-start | inline-end | block-start | block-end">
    <InputGroupText />
    <InputGroupButton />
  </InputGroupAddon>
</InputGroup>
```

An addon's place comes from `align`, not from where it sits in the markup: write the input first, then its addons.

## Examples

### Buttons

`InputGroupButton` is a ghost [Button](/docs/components/button) at the one compact size, so it sits inside the 28 px field. Use `xs` for a word (Copy) and `icon-xs` for an icon alone (Clear search).

### Textarea

With `InputGroupTextarea` the group grows to fit, and a `block-end` addon becomes the field's footer: a counter and the send button of a chat composer.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `h-control` | The 28 px group height; `h-auto` with a textarea or a block addon |
| `rounded-chip` | The 6 px control radius |
| `bg-input/50` | The recessed field fill, on the group |
| `data-align` | The addon's place: `inline-start`, `inline-end`, `block-start`, `block-end` |
| `data-disabled="true"` on the group | Dims the addons |
| `data-slot` | `input-group`, `input-group-addon`, `input-group-text`, `input-group-control` |

## Accessibility

The group is a `role="group"`. Name the input itself: an `aria-label`, or a `FieldLabel` when the group sits in a [Field](/docs/components/field). An icon-only `InputGroupButton` needs an `aria-label`. A click on an addon's text or icon focuses the input; a click on its button doesn't.
