## Installation

```npm
npx shadcn@latest add @videorc/progress
```

## Usage

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress";
```

```tsx
<Progress aria-label="Update download" value={64} />
```

## Anatomy

`Progress` draws its own track and indicator after its children, so a label and a value sit above the bar.

```tsx
<Progress>
  <ProgressLabel />
  <ProgressValue />
</Progress>
```

## Examples

### Steps

`value` runs from 0 to `max` (100 by default), so count steps directly. `ProgressValue` takes a function to say the count in words.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `chrome-fill` | The indicator: the same polished chrome as the primary button |
| `bg-muted`, `rounded-full`, `h-1.5` | The 6 px round track |
| `duration-150 ease-out` | The indicator's width change |
| `data-progressing`, `data-complete` | On every part, from Base UI |

## Accessibility

Base UI renders a `progressbar` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`, and `aria-valuetext` as a percentage. `ProgressLabel` names the bar; without one, pass `aria-label`. A bar is never the only place a fact lives: put the number or the step in words beside it ("3 of 8", "Uploading recording…").

Progress is for work with a known end. For work without one, use a spinner and a pending label that ends in "…".

Every [Base UI Progress Label and Value](https://base-ui.com/react/components/progress) prop. `ProgressValue` takes `(formattedValue, value) => ReactNode` as its child.

The parts `Progress` draws for you, exported for a custom layout.
