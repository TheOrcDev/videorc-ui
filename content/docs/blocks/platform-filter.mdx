title: Platform Filter

---

## Installation

```npm
npx shadcn@latest add @videorc/platform-filter
```

## Usage

```tsx
import {
  PlatformFilter,
  PlatformFilterMenuItems,
} from "@/components/blocks/stream-manager/platform-filter";
```

```tsx
<PlatformFilter
  label="Show chat from"
  onValueChange={setPlatform}
  platforms={["youtube", "twitch", "x"]}
  value={platform}
/>
```

Chat and Activity share it, so a platform filters the same way in both. A chip clicked again turns back to All. With one platform it renders nothing: there's nothing to filter by.

Below 640 px of Stream Manager the chips move into the pane's Filters menu: put `PlatformFilterMenuItems` inside a [Dropdown Menu](/docs/components/dropdown-menu), with the same props. [Chat Toolbar](/docs/blocks/chat-toolbar) does both.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `ToggleGroup` | The chips; the chosen one is the chrome plate |
| `ChatPlatformIcon` | Each platform's 20 px mark |
| `data-slot="platform-filter"` | The group |

## Accessibility

The group is named by `label` ("Show chat from"). Each icon chip is named by its platform and says "Only YouTube" on hover. In the menu, the choice is a radio group under the same label, with "Every platform" first.
