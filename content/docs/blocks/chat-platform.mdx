## Installation

```npm
npx shadcn@latest add @videorc/chat-platform
```

## Usage

```tsx
import {
  CHAT_PLATFORM_LABELS,
  ChatPlatformIcon,
  chatStateLabel,
} from "@/components/blocks/stream-manager/chat-platform";
```

```tsx
<ChatPlatformIcon platform="twitch" />
```

Every Stream Manager part names a platform through it: a message's mark, the filter chips, the stats' hover cards and the status bar's chat states. Pass `decorative` when the words beside the mark already name the platform.

## Examples

### Chat states

`chatStateLabel(destination)` turns a destination's connection into Videorc's chat vocabulary: "Connected", "Read-only", "Reconnect to send", "Reconnecting…". It never says "receive-only", and never shows a raw value.

## The marks

Platform marks are the one place saturated colour is allowed in the chrome. Each mark is 20 px wherever it appears: YouTube's icon may not go below 20 px, so the others match it, and YouTube keeps clear space after it. A surface with no room for 20 px, such as a [Badge](/docs/components/badge), leaves the mark out and keeps the platform's name. The glyphs come from [Icons](/docs/concepts/icons) (`YoutubeIcon`, `TwitchIcon`, `XPlatformIcon`…), so swapping one there swaps it here.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `text-platform-youtube`, `text-platform-twitch-ink`, `text-platform-facebook`, `text-platform-instagram` | The brand tints |
| `text-foreground` | X and TikTok: black or white by theme |
| `size-5` | The 20 px mark |
| `data-platform` | The platform the mark stands for |
| `data-slot="chat-platform-icon"` | The mark |

## Accessibility

A mark is an image named by its platform. With `decorative` it's hidden from assistive tech, so the platform is named once.
