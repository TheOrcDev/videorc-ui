videorc/ui is where Videorc's interface is designed and kept. Every button, menu, row and pane the desktop app draws starts here, and the app installs it with the same `shadcn` CLI you use.

It is a [shadcn registry](https://ui.shadcn.com/docs/registry): you get the source, in your project, and you own it.

## Principles

- **Color is information.** The chrome is monochrome. Saturated color appears only in status (live, success, warning, destructive) and in source icons.
- **A desktop app, not a page.** Controls are desktop-sized (28 px), rows are 32 px, toolbars 40 px. Every primary action has a keyboard shortcut.
- **One primitive per job.** A list of like things is a `GroupedList` of `ListRow`s, a confirmation is a `ConfirmDialog`, a shortcut is `ShortcutKeys`. Screens compose primitives; they don't restyle them.
- **Dark first, light as its twin.** Dark is the reference; light is the same structure in porcelain and graphite.
