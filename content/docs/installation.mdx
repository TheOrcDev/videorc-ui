title: Installation
description: Add the videorc/ui registry to a shadcn/ui project and install the theme and components with the shadcn CLI.
---

videorc/ui is a [shadcn registry](https://ui.shadcn.com/docs/registry). You add components with the `shadcn` CLI, and the code lands in your project.

## Requirements

- React 19.2 or later and Tailwind CSS v4.
- A shadcn/ui project on Base UI (a `base-*` style). The components import `@base-ui/react`.
- `shadcn/tailwind.css` imported in your global stylesheet, after `tailwindcss`. It defines the `data-open`, `data-checked`, `data-horizontal` and other variants the components style with. Every `base-*` project has it.

<Steps>

<Step>

### Set up shadcn/ui

Skip this if your project already has a `components.json`.

```npm
npx shadcn@latest init --base base
```

</Step>

<Step>

### Add the registry

Add the `@videorc` namespace to `components.json`:

```json title="components.json"
{
  "registries": {
    "@videorc": "https://ui.videorc.com/r/{name}.json"
  }
}
```

</Step>

<Step>

### Add the theme

```npm
npx shadcn@latest add @videorc/theme
```

This merges the Videorc tokens, utilities and base layer into your global stylesheet. Every component depends on it, so the CLI also adds it with the first component you install.

For a desktop app (Electron, Tauri), also add `@videorc/desktop`: chrome text stops selecting, the arrow stays the pointer, and the window stops rubber-banding.

```npm
npx shadcn@latest add @videorc/desktop
```

</Step>

<Step>

### Add a component

```npm
npx shadcn@latest add @videorc/button
```

</Step>

</Steps>

## What gets installed

| Path | What it is |
| --- | --- |
| `components/ui/*` | Components, one file each |
| `components/*` | Primitives: rows, panes, status bars, menus |
| `components/icons.tsx` | The semantic icon set every component draws from |
| `hooks/*`, `lib/*` | The shared hooks and helpers |
| Your global CSS | The theme: tokens in light and dark, `@theme` mappings, utilities, base layer |

Paths follow the aliases in your `components.json`, so they adapt to a `src/` folder or custom aliases.

## The ground

Videorc's surfaces are translucent coats, tuned to sit on a window's solid tone. On a plain page, give the page the theme's solid so the coats composite to the right tone:

```css title="app/globals.css"
@layer base {
  html {
    background-color: var(--glass-solid);
  }
}
```
