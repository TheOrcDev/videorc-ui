## Installation

```npm
npx shadcn@latest add @videorc/kebab-menu
```

## Usage

```tsx
import { KebabMenu } from "@/components/kebab-menu";
```

```tsx
<KebabMenu
  items={[
    { id: "rename", label: "Rename…", icon: EditIcon, onSelect: rename },
    {
      id: "delete",
      label: "Delete…",
      destructive: true,
      onSelect: askToDelete,
    },
  ]}
  label="Actions for Launch demo"
/>
```

Use it for per-item actions in every list and card: recordings, assets, scenes, scheduled livestreams, chat rows. The row's primary action stays a click on the row; the menu holds what you do less often.

Don't build a menu by hand for a row, and don't put the row's one main action in it.

## Examples

### Groups, keys and a busy item

Items with the same `group` sit together, a hairline between groups, in the order each group first appears. Destructive items always go last, in a group of their own. `shortcut` takes a [Shortcut Keys](/docs/components/shortcut-keys). While an item's work runs, `busy` swaps the dots for a spinner, and a disabled item says why on hover.

<ComponentPreview name="kebab-menu-groups" />

### Revealed on hover

`reveal="hover"` hides the trigger until its host row is hovered or holds focus. Mark the row with `group/kebab-host`. The trigger stays visible while its menu is open, while it has keyboard focus and while it's busy.

<ComponentPreview name="media-card-backgrounds" />

### With a confirm dialog

A destructive item that can't be undone opens a [Confirm Dialog](/docs/primitives/confirm-dialog), and its label ends in "…". The recordings list above does this for Delete.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `Button` `ghost`, `size="icon"` | The 28 px trigger |
| `group/kebab-host` | The row the trigger waits for with `reveal="hover"` |
| `data-popup-open` | On the trigger while its menu is open; keeps it visible |
| `aria-busy` | On the trigger while `busy`; keeps it visible |

## Keyboard

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> <kbd>Space</kbd> | On the trigger, opens the menu |
| <kbd>↑</kbd> <kbd>↓</kbd> | Moves through the items, disabled ones included |
| <kbd>Enter</kbd> | Runs the highlighted item |
| <kbd>Esc</kbd> | Closes the menu and returns focus to the trigger |

## Accessibility

The trigger is a button named by `label`: name the item it acts on ("Actions for Launch demo"), never just "More". A click on the trigger or in the menu never reaches a clickable row behind it. A disabled item stays in the arrow-key order and is described by its `disabledReason`, through [Disabled Reason](/docs/components/disabled-reason).
