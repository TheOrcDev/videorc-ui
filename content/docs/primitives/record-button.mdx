## Installation

```npm
npx shadcn@latest add @videorc/record-button
```

It brings [Button](/docs/components/button) with it.

## Usage

```tsx
import { RecordButton } from "@/components/record-button";
```

```tsx
<RecordButton onClick={toggleRecording} state={session} />
```

`state` is where the session stands, and comes in from your app: `idle`, `starting` after the click, `running` once it records or streams, and `stopping` while it finishes. The button picks its glyph, lights its LED and says each state's words. Pass your own words as children ("End livestream" while on air, "Force stop" after a stop that drags on).

Use it for Record and the button that stops the session, and nothing else: a lit LED only ever means record or live. Delete stays a `destructive` Button, and Go Live… stays the chrome primary beside it.

## Examples

### States

Starting and stopping answer from the click: the lens is lit, the button takes no click, keeps its focus and doesn't dim. Only a running session's bloom breathes. Blocked is a disabled button, flat and dimmed; say why with [Disabled reason](/docs/components/disabled-reason).

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `chrome-led` | The material, on Button's `record` variant |
| `--chrome-led-off-stops`, `--chrome-led-stops` | The lens, switched off and lit |
| `--chrome-led-dome`, `--chrome-led-rim-light` | The lens's dome of light, and the light at its rim while lit |
| `--chrome-led-glow` | The bloom past the bezel |
| `--chrome-chromatic-bands` | The bezel's metal, the chromatic ring's, held still |
| `data-lit` | Lights the LED: set from `starting` on |
| `data-state` | `idle`, `starting`, `running` or `stopping` |

Every lens stop keeps the white label at 4.5:1 or more in both themes, so the light comes from the rim and the bloom, never from a brighter face. The bloom is a layer of its own that breathes on opacity alone, so a session that runs for hours never repaints the button. Under reduced motion, it holds steady. Increase Contrast adds an edge around the bezel, and forced colours draw it as a border.

## Keyboard

| Key              | Action                      |
| ---------------- | --------------------------- |
| `Enter`, `Space` | Starts or stops the session |

A shortcut for Record belongs to the page, not to the button. Show it inside with [Shortcut Keys](/docs/components/shortcut-keys).

## Accessibility

It's a one-shot action whose words change ("Record", then "Stop recording"), so it takes no `aria-pressed`. While starting or stopping, it's `aria-disabled` and stays focusable, so keyboard focus isn't lost under the user's hands. Announce the session's state in a status region, such as a [Status Badge](/docs/primitives/status-badge) with `role="status"`, not on the button.
