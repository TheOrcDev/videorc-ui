## Installation

```npm
npx shadcn@latest add @videorc/list-row
```

## Usage

```tsx
import { GroupedList, ListRow, ListRowButton } from "@/components/list-row";
```

```tsx
<GroupedList label="Cameras">
  <ListRow
    context="Built-in"
    icon={<CameraIcon />}
    meta="In use"
    title="FaceTime HD Camera"
  />
</GroupedList>
```

Use it for sets of like things: sources, devices, destinations, scenes, settings. Lists, not card stacks: a card is only for an object with a picture, such as a scene thumbnail or a background.

Don't hand-roll an icon, title and meta row, and don't put cards inside a grouped list. A fact row that jumps to the page owning its value is a [Navigable Row](/docs/primitives/navigable-row).

## Anatomy

```tsx
<GroupedList label>
  <ListRow leading icon title context alias statusIcons meta>
    {/* trailing controls */}
  </ListRow>
</GroupedList>
```

## Examples

### A row with its own controls

A row that holds a control, such as a switch, stays a `div`. Put a `ListRowButton` in its `title` and give the row `relative`: the button stretches over the whole row, so a click anywhere on it acts, while the switch stays its sibling instead of nesting inside a button. `interactive` adds the hover.

<ComponentPreview name="list-row-controls" />

### The whole row as a button

`as="button"` makes the row one button, with the hover and the focus ring. `selected` draws the accent block; pair it with `aria-pressed` or `aria-current`. `compact` is 28 px.

## Theming

| Token or attribute | Meaning |
| --- | --- |
| `h-row`, `h-row-compact` | 32 px, or 28 px when `compact` |
| `rounded-row` | 8 px on a row alone; none inside a GroupedList, which owns the radius |
| `bg-inset`, `divide-border` | The grouped list's inset fill and its hairlines |
| `bg-accent` | The hover of an interactive row, and the selected row |
| `text-meta` | The 12 px meta label |
| `data-selected` | On a selected row |
| `data-slot="platform-mark"` | On a platform mark in the icon tile: it's never clipped to the chip radius |
| `data-slot` | `list-row`, `list-row-icon`, `list-row-title`, `list-row-context`, `list-row-meta`, `grouped-list`, `list-row-button` |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves to a row that's a button or holds a ListRowButton, then to the row's own controls |
| `Enter`, `Space` | Activates it |

## Accessibility

A fact row is plain text. A row that's a button is named by its content, the title, context and meta in order, so keep the meta short. Selection is a block of colour: say it with `aria-pressed` or `aria-current` too. A trailing control needs its own name ("Stream to YouTube").

GroupedList passes its attributes to the list itself, so `aria-label` names the group for assistive tech.
